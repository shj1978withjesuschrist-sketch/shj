# 버블버블 (Bubble Bobble-Inspired)

작은 HTML5 캔버스 게임입니다. 키보드로 캐릭터를 움직이며 버블을 발사해 적을 가둔 뒤 터뜨려 점수를 얻습니다.

## 실행 방법
1. 저장소 루트에서 `index.html`을 브라우저로 열면 됩니다.
2. 조작법
   - ← → : 이동
   - Z : 점프
   - X : 버블 발사
   - 다시하기 버튼: 스테이지 리셋

## 게임 규칙
- 적을 버블에 가두고 플레이어가 터치하면 제거되며 점수를 얻습니다.
- 적과 직접 충돌하면 게임 오버입니다.
- 모든 적을 제거하면 스테이지 클리어 메시지가 표시됩니다.
